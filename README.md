# AgentGuard

Production control plane for AI coding agents.

> **AgentGuard lets engineering teams give AI coding agents more autonomy without giving up production safety.**

## Start here

1. Read **[`AGENTGUARD.md`](AGENTGUARD.md)** (master specification).
2. Browse topic docs under [`docs/`](docs/).
3. Implement **one milestone at a time** — begin with **M0** using the prompt in `AGENTGUARD.md` §82 / [`docs/24-codex-development-rules.md`](docs/24-codex-development-rules.md).
